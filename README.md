# Dota Advisor

Оверлей для Dota 2, который на этапе драфта подсказывает, **кого пикать против вражеской команды** и **какие предметы купить**.

Программа сама находит вражеских героев на экране, считает контрпики по статистике матчей (OpenDota) и показывает результат в удобной панели прямо поверх игры.

> Программа только смотрит на экран и список процессов. Она ничего не внедряет в Dota 2 и не читает память игры.

## Для чего это нужно

- подобрать героя, который хорошо играет против вражеского драфта;
- получить советы по ситуативным предметам (против невидимости, магического урона, регенерации, станов и т. д.);
- быстро сориентироваться в драфте, не сворачивая игру.

## Как пользоваться

### 1. Подготовка

В настройках Dota 2 выберите режим экрана **«Окно без рамки»** (Borderless). В полноэкранном режиме оверлей не будет виден.

### 2. Запуск

Запустите Dota Advisor. На экране появится маленькая изумрудная иконка-ромб.

- **Клик по иконке** или клавиша **F8** открывает и скрывает панель по центру экрана.
- Иконку можно перетащить мышью в удобное место.
- **Правая кнопка** по иконке открывает меню с пунктом «Выход».

Если при установке вы включили автозапуск, программа стартует вместе с Windows, а иконка появляется сама, пока запущена Dota 2.

### 3. Первая настройка

1. Откройте драфт или игру, где видны портреты героев.
2. В панели нажмите **«Выбрать область»** и обведите рамкой ряд с портретами героев. Чем плотнее рамка, тем быстрее и точнее распознавание.
3. Нажмите **«Скан»**. Включённый переключатель **«Авто»** сканирует область сам каждые несколько секунд.

Область запоминается, повторно выбирать её не нужно.

Если в рамку попали обе команды, включите **«Обе команды»**. Переключатель **«Мои слева»** указывает, с какой стороны ваша команда.

### 4. Что показывает панель

- **Враги / союзники:** распознанные герои.
- **Кого брать:** рекомендуемые герои по ролям 1–5 и их преимущество против врагов в процентных пунктах винрейта. Выбрав нужную роль в строке «Роль», вы увидите больше вариантов именно для неё.
- **Что купить:** ситуативные предметы под состав врагов.

### 5. Дополнительные настройки

Откройте **«Настройки»** в панели:

| Поле | Для чего |
|---|---|
| Враги вручную | Ввести героев руками (например, `pudge, pa, lion, sf, axe`), если автоскан не нужен. Поддерживаются сокращения. Чтобы вернуться к автоскану, очистите поле. |
| Союзники | Герои вашей команды, чтобы их не предлагали как пик. |
| Мой пул героев | Список героев, которыми вы играете. Советы будут выбираться только из него. |
| Порог узнавания | Насколько строго сверять портреты. Если герой не распознаётся, снизьте значение, например до 0.65–0.70. Если распознаются лишние, повысьте. |

В нижней строке панели видно, насколько уверенно распознаны герои, это помогает подобрать порог.

## Примечания

- При первом запуске программа скачивает портреты героев, это занимает около минуты. Нужен интернет.
- Герои с значком тира на портрете тоже распознаются.
- Повторный запуск не создаёт копию: программа сообщит, что уже работает.
